## 2024-05-24 - IntersectionObserver Over querySelectorAll for Render Loops
**Learning:** Calling `document.querySelectorAll()` inside a recursive `requestAnimationFrame` loop creates an O(N) performance bottleneck and generates unnecessary garbage. When a scene contains many DOM elements tied to 3D elements (like avatar placeholders), continually querying the DOM causes significant main-thread latency.
**Action:** Instead of querying the DOM on every frame, use a combination of `IntersectionObserver` (with an appropriate rootMargin) and `MutationObserver` to maintain a reactive Set (`visibleAvatars`) of elements currently in the viewport. Loop over this pre-filtered Set during the animation frame, converting the operation from O(N) DOM queries to O(M) iteration (where M is the number of visible elements).
