## 2024-03-01 - Optimizing RequestAnimationFrame Loops via IntersectionObserver Caching
**Learning:** In applications relying heavily on recursive `requestAnimationFrame` for animations (like rendering 3D avatars via Three.js), querying the DOM layout (`document.querySelectorAll`) inside every frame drastically increases overhead and causes layout thrashing because it is O(N) over all elements regardless of their visibility, reducing frame rate.
**Action:** Replace frame-level DOM queries with event-driven state tracking. Use an `IntersectionObserver` coupled with a `MutationObserver` (to track dynamic DOM insertion/removals) to cache visibility inside a lightweight data structure like a `Set`. Iterate over this `Set` (O(M), M <= N) inside the render loop to decouple layout logic from paint logic, achieving significant performance improvements.
