## 2024-05-24 - Optimize high-frequency DOM queries and layout thrashing in animate loop
**Learning:** In high-frequency execution paths like `requestAnimationFrame` loops (e.g., `animate` in `avatar.js`), using `document.querySelectorAll` creates unnecessary overhead because it returns a static NodeList, whereas `document.getElementsByClassName` returns a live, faster `HTMLCollection`. Furthermore, accessing layout properties like `window.innerHeight` or array lengths repeatedly within the loop causes layout thrashing.
**Action:** Always use `document.getElementsByClassName` instead of `querySelectorAll` for class-based queries in animation loops, and ensure layout properties (like `window.innerHeight`) and collection lengths are cached outside the loop to prevent redundant overhead.
