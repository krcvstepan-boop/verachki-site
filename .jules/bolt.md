## 2024-05-24 - Optimize Avatar Render Loop
**Learning:** Per-frame DOM queries (`document.querySelectorAll`) inside an animation loop (like in `animate()` of `SoulAvatarSystem`) become a significant bottleneck as the DOM grows. The performance baseline for querying 100 elements is ~0.0068ms, which adds up quickly and degrades frame rates.
**Action:** Replace $O(N)$ DOM querying with an $O(M)$ reactive Set iteration. Use an `IntersectionObserver` to track the visibility of elements, adding and removing them from a `visibleAvatars` Set. Combine this with a `MutationObserver` on the parent container to attach the intersection observer to newly added elements and to properly clean up outgoing ones, preventing memory leaks and removing per-frame DOM query overhead completely.
